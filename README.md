# OI 重开模拟器 v0.4.0-beta

> 人生重开模拟器的 OI 竞赛版本 —— 36 月回合制，体验一名 OIer 的完整高中生涯

基于 Dear ImGui 的图形界面版本。原项目 [Little09qwq/oi-remake-game](https://github.com/Little09qwq/oi-remake-game)

月回合制的设计灵感来自[这篇洛谷讨论](https://www.luogu.com.cn/article/md0iry4t)（[保存站链接](https://www.luogu.me/article/md0iry4t)）。

## 功能特性

- **36 月回合制**：3 年高中生活，每月自由分配行动力（AP）
- **9 维知识体系**：DP / 数据结构 / 字符串 / 图论 / 组合计数 / 数学 / 几何 / 高级数据结构 / 构造
- **完整赛季**：CSP-S → NOIP → WC → 省选 → APIO → NOI → CTT → CTS → IOI
- **文化课考试**：期中 / 期末 / 高考独立系统，跨年文化效率加权
- **背景与特质**：7 种开局背景 + 8 种可获取特质
- **焦虑与遗忘**：心态持续低迷触发焦虑，长期不学则知识遗忘
- **金钱商店**：月收入 + 比赛奖金，价格递增
- **暑假集训**：7-8 月高强度训练选项
- **115 道题目**：覆盖入门到 NOI+ 全级别
- **4 档难度**：简单 / 普通 / 困难 / 专家
- **存档系统**（v0.3.0）：月翻页自动存档，主菜单一键继续
- **专题任务**（v0.3.0）：11 个专题，完成得永久「精通」加成
- **生活节奏**（v0.3.0）：体育锻炼、熬夜冲刺、病倒静养
- **保送与结局矩阵**（v0.3.0）：集训队锁定保送；OI 高度 × 高考档位 = 8 种结局称号 + 三年大事记
- **机房伙伴与宿敌**（v0.4.0）：3 位随机伙伴（姓名/专精/效果随机），闲聊养关系解锁挚友效果与知己倾诉；教练关系解锁特训；宿敌每场正式比赛对比播报，知耻后勇机制
- **结局后继承**：规划中——见 [功能设计评审](docs/v0.3.1-changelog.md)

> 详细更新说明见 [`docs/v0.4.0-changelog.md`](docs/v0.4.0-changelog.md)

## 游戏循环

1. **开局** — 选择难度档位 → 分配天赋 → 选择背景 → 随机生成 3 位机房伙伴与 1 位宿敌
2. **月度行动** — 每月获得行动力（AP），自由执行活动：学习、网赛/刷题、专题、文化课、锻炼、休息、闲聊、商店……
3. **结束本月** — 进入阶段队列：官方比赛 → 考试 → 结算，按月历自动排定
4. **结算** — 未用 AP 转恢复、心态调整、遗忘判定、金钱收入、焦虑与病倒判定
5. **翻页** — 循环 36 个月（高一暑假 → 高三高考），期间可能触发保送；终局由 OI 高度 × 高考档位决定结局称号

## 获取源码

本项目使用 [Git 子模块](https://git-scm.com/book/en/v2/Git-Tools-Submodules) 管理 Dear ImGui 依赖，克隆时**必须递归初始化子模块**：

```bash
git clone --recurse-submodules https://github.com/Andy-Xie-1145/OI-Remake-Simulator.git
```

如果已经克隆但忘记加 `--recurse-submodules`，执行以下命令补全：

```bash
git submodule update --init --recursive
```

> 未初始化子模块会导致编译失败（找不到 `imgui/imgui.h`）。

## 编译方法

### 前置要求

- Windows 系统
- DirectX 11（Windows 自带）
- C++17 编译器

### 方法一：使用 build.bat（Visual Studio，推荐）

1. 双击运行 `build.bat`
2. 脚本会自动找到 Visual Studio 并编译

### 方法二：使用 build_mingw.bat（MinGW-w64）

1. 确保已安装 [MinGW-w64](https://github.com/niXman/mingw-builds-binaries/releases)（或通过 MSYS2：`pacman -S mingw-w64-x86_64-gcc`）
2. 双击运行 `build_mingw.bat`

### 方法三：使用 CMake

```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

## 运行

> 前往 [Releases](https://github.com/Andy-Xie-1145/OI-Remake-Simulator/releases/latest) 下载最新版本的 exe，开箱即用。

如需手动编译，编译成功后运行 `output/oi_simulator_gui.exe`。

## 项目结构

| 文件 | 说明 |
|------|------|
| `main.cpp` | 主程序入口、UI 渲染（纯视图） |
| `month_engine.hpp` | 月度引擎（回合流程、活动成本、商店交易的唯一规则归属地） |
| `save_system.hpp` | 存档系统（key-value 序列化，自动/手动存读档） |
| `topics.hpp` | 专题任务系统（进度 / 精通 / 逾期） |
| `ending.hpp` | 结局矩阵（OI 高度 × 高考档位 → 结局称号与结语） |
| `types.hpp` | 类型定义、常量、难度配置 |
| `game.hpp` | 游戏逻辑（月度结算、焦虑、遗忘、经验） |
| `story.hpp` | 月历引擎（36 月时间线、比赛/考试安排） |
| `activities.hpp` | 月度活动定义与执行 |
| `talents.hpp` | 背景系统 + 特质获取 |
| `culture_exam.hpp` | 文化课考试系统 |
| `contest.hpp` | 比赛逻辑（思考/写代码/对拍/评奖） |
| `events.hpp` | 属性变更唯一入口 + 商店 |
| `social.hpp` | 机房伙伴 / 教练 / 宿敌（生成、关系、挚友效果、对比播报） |
| `problem_pool.hpp` | 题目池 (115 题) |
| `imgui/` | Dear ImGui（Git 子模块） |

自动化测试位于 [`tests/`](tests/)（Catch2，含引擎级无头回归测试），运行 `tests/build_test_mingw.bat` 一键编译执行。架构决策见 [`docs/adr/`](docs/adr/)。

## 术语表

### 时间与回合

- **月回合**：基本时间单位，共 36 个，从高一前暑假（第 1 年 7 月）到高考（第 3 年 6 月）
- **阶段**：结束自由行动后的固定事件序列：官方比赛 → 考试 → 结算
- **结算**：每月恰好执行一次的月末汇总（恢复 / 心态 / 遗忘 / 收入 / 焦虑 / 病倒）
- **结算事实**：结算产生的带类别记录（健康 / 知识 / 经济 / 其他），结算页按类别分组展示

### 资源与属性

- **行动力（AP）**：每月可支配的行动点数，基础 8 点，受停课 / 熬夜 / 难度 / 赛事月增减
- **知识维度**：九个算法方向（DP / 数据结构 / 字符串 / 图论 / 组合计数 / 数学 / 几何 / 高级数据结构 / 构造），初始值由天赋分配决定
- **能力值**：思维、代码、细心、迅捷、心理素质、经验、运气等辅助属性，影响比赛公式与事件概率；所有属性上限 20
- **文化课**：与竞赛争夺时间的学业属性；影响考试得分与月收入，高考是其终局考核
- **健康**：0–20 的生存资源，归零即游戏结束
- **金钱**：来源于月收入与比赛奖金，用于商店购买属性提升（价格随购买递增）
- **心态上限**：玩家当前的心态最大值，随背景变化（10–14）

### 人物系统

- **难度档位**：简单 / 普通 / 困难 / 专家，决定天赋点、起始金钱与收入、分数线倍率与事件烈度
- **天赋**：开局把天赋点分配到九维知识作为初始值
- **背景**：开局一次性选择的出身（7 种），决定初始属性加成与全局修正
- **特质**：通过模拟赛 / 刷题有概率获得的能力标签（最多 4 个）

### 竞赛

- **官方比赛**：月历排期、按成绩判定资格的赛事（CSP-S → NOIP → WC → 省选 → APIO → NOI → CTT → CTS → IOI），多为连续两日
- **活动比赛**：作为月度活动发起的比赛（网赛、刷题、自定义模拟赛），结束后按类型概率掉落特质
- **比赛流程**：思考 → 写代码 → 对拍/提交；耗时与成功率由思维 / 代码 / 细心 / 心态与题目要求共同决定
- **资格线**：进入 WC / 省选 / APIO 等赛事所需的 NOIP 分数门槛（180 × 难度倍数）
- **文化课考试**：期中 / 期末 / 高考按月历触发；阅读 → 作答或蒙题 → 检查；正确率由文化课与思维决定
- **高考**：第 36 月的终局考核；保送者替换为庆功月

### 目标与生活

- **专题任务**：接受后 3 个月内完成 4 次匹配行动的长线目标；同时最多一个
- **精通**：完成专题获得的永久加成（该维度思考时间 −1 / 迅捷 +1 / 错误率 ×0.9）
- **体育锻炼**：1 AP；健康 +2，本月 ≥2 次则病倒概率减半
- **熬夜**：月度开关，+2 AP；结算健康 −3、焦虑概率 ×1.3；与停课互斥
- **停课**：月度开关，+2 AP；心态代价（教练关系 ≥40 时减轻）、禁止学文化课
- **病倒**：健康 ≤4 时月末有概率触发；下月行动力 −2、心态 −1，不可清除
- **焦虑**：心态 <4 连续 2 个月触发；学习效率 ×0.7，可向知己倾诉清除
- **遗忘**：连续 2 个月未学习的维度 / 文化课自动 −1

### 人际

- **机房伙伴**：开局随机生成的同学 ×3（姓名 / 专精 / 挚友效果随机互异）；高三开学每人 20% 概率退环境，保底留一人
- **挚友效果**：关系 ≥40 生效的专属加成（代码复查 / 灵感碰撞 / 错题本 / 补习互助 / 心态锚），达成时揭示
- **知己**：关系 ≥85；解锁「倾诉」按钮（0 AP 清焦虑，每学年一次）
- **教练**：获奖 +10 / 参训 +5 / 文化薄弱 −2；≥40 停课减罚，≥70 解锁特训
- **宿敌**：开局随机生成的同省竞争者；每场正式比赛播报对比
- **知耻后勇**：输给宿敌后 2 个月学习效率 ×1.1
- **集训**：暑假（7–8 月）限定高强度训练；教练关系 ≥70 效果增强

### 终局

- **保送**：入选国家集训队触发；文化课压力解除，高考替换为庆功月
- **结局称号**：OI 高度 × 高考档位（或健康归零）共同决定的结局名称与专属结语
