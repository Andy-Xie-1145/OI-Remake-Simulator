# 所有属性变更走 applyStatDelta 单一入口

心态上限曾有两套真相：MOOD_LIMIT=12 常量在 10 处各自 clamp，而背景相关的
moodCap（佛系心态=14）只在月度结算生效——「佛系」玩家战斗内心态永远加不过 12。
2026-08 起规定：任何对 mood / health / money / 九维知识 / 能力值的增减必须经过
`events.hpp` 的 `applyStatDelta`，边界与上限由它统一裁决；新增机制不得直接写
`gameState.mood` 或成员字段。字符串键拼错会在运行期日志中留下
「未知属性键」警告。

已知取舍：键仍是字符串（数据驱动的商店/学习表依赖它），没有升级为编译期枚举；
若未来键数量膨胀或警告频繁出现，再考虑枚举化。
