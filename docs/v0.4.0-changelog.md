## 🛠 beta.2 修正（2026-08-26）

- **行动力明细**：月度头卡实时展示 AP 构成算式，赛事/考试月的预先扣减一目了然
- **专题进度统一为「接受后才开始计数」**：移除细心打磨对历史对拍的回溯；手速特训锁定为每场活动比赛恰好 +1（回归测试覆盖）
- **新增「倾诉」独立按钮**（0 AP）：焦虑时向知己直接清焦虑，不再隐藏在闲聊自动触发里
- **修复**：网赛/刷题误触发宿敌对比与教练关系的问题（活动比赛不再结算宿敌逻辑）

三年高中不该只有你和题目。v0.4.0 把「人」带进机房：随机生成的伙伴、有脾气的教练、如影随形的宿敌——焦虑终于有了倾诉对象，失败也有了具体的样子。

## 🆕 机房伙伴

- 开局**随机生成 3 位伙伴**：姓名来自随机姓名库，专精维度互异，挚友效果从效果池随机分配（同局互不重复）
- 新活动 **「机房闲聊」（1 AP）**：关系 +4~7，30% 触发小增益（对方专精维度 +1 / 心态 +1）
- **关系层级**：
  - **挚友（≥40）**：解锁专属效果（达成时揭示）
  - **知己（≥85）**：解锁「倾诉」——焦虑状态下闲聊即清焦虑，每学年一次
- 挚友效果池（5 选 3 随机分配）：

| 效果 | 说明 |
|------|------|
| 代码复查 | 比赛中「代码bug」事件概率 ×0.7 |
| 灵感碰撞 | 「灵光一闪」事件概率 +1% |
| 错题本 | 对拍失败后修改代码所需次数 −1 |
| 补习互助 | 学文化课时文化课收益额外 +1 |
| 心态锚 | 焦虑发作概率 ×0.85 |

- **高三扰动**：开学时每人 20% 概率退环境（挚友效果随之失效），但保证至少一人陪你走到最后

## 🆕 教练

- 关系来源：正式比赛获奖 +10 / 参加集训 +5 / 文化课薄弱月 −2
- **关系 ≥40**：停课心态惩罚 −3 → −2
- **关系 ≥70**：解锁「教练特训」标签（集训效果增强的基础）

## 🆕 宿敌

- 开局随机生成同省竞争者（随机姓名），强度系数在玩家预期分的 0.90~1.15 倍浮动
- 每场正式比赛结算后播报双方对比
- **输**：心态 −2，但获得 2 个月「知耻后勇」（学习效率 ×1.1）
- **赢**：心态 +1
- NOI 决胜压过宿敌 → 隐藏成就「一生之敌」
