# OI 重开模拟器 v0.2.0 更新说明

> 从 v0.1.5-beta 线性剧情版 → v0.2.0 月回合养成版

v0.2.0 的设计灵感源自[这篇洛谷帖子](https://www.luogu.com.cn/article/md0iry4t)（[保存站链接](https://www.luogu.me/article/md0iry4t)）中提出的月回合制构想。

## 一句话概括

游戏从"固定剧情序列推进"重构为"36 月自由回合制养成"——玩家每月自主分配行动力，在 OI 竞赛和文化课之间取舍，三年后看结局。

---

## 架构变化

| 维度 | v0.1.5（旧） | v0.2.0（新） |
|------|-------------|-------------|
| 时间线 | 线性 phase 1-55，固定事件序列 | 36 月（3 学年）月回合制，自由行动 |
| 核心资源 | 决心（determination） | 金钱（money）+ 行动力（AP） |
| 每回合 | 触发预设训练事件，选择选项 | 消耗 AP 执行活动（学习/比赛/休息等） |
| 比赛触发 | 剧情节点自动进入 | 比赛月在活动结束后自动进入 |
| 文化课 | 无实际玩法 | 独立考试系统（期中/期末/高考） |
| 知识维度 | 5 维（dp/ds/string/graph/combinatorics） | 9 维（+数学/几何/高级数据结构/构造） |
| 心态上限 | 固定 12 | 由背景决定（10-14） |
| 游戏结束 | 打完所有阶段 | 健康归零 或 36 月结束 |

## 新增系统

### 月回合制（`story.hpp` / `activities.hpp`）

- 每月基础 8 AP，停课 10 AP（心态-3，禁文化课）
- 比赛月/考试月扣 5 AP
- 未用 AP 月末自动转为健康和心态恢复

活动列表：

| 活动 | AP 消耗 | 说明 |
|------|---------|------|
| 学习知识 | 2 | 选择 9 个维度之一 |
| 打网赛 | 3 | 完整比赛流程，洛谷/CF/AtCoder 等 |
| 刷题练习 | 2 | 按洛谷难度刷一道题 |
| 自定义模拟赛 | 4 | 自选难度模板 |
| 学文化课 | 2 | 文化课+2，心态+1 |
| 休息 | 2 | 健康+3，心态+2 |
| 暑假集训 | 4 | 7-8 月限定，高强度训练 |
| 商店 | 0 | 金钱购买属性提升（价格递增） |

### 文化课考试系统（`culture_exam.hpp`）

- 考试月：11 月期中、1 月期末、4 月期中、6 月期末
- 每题 4 阶段：阅读 → 作答/蒙题 → 检查（可选）→ 完成
- 作答正确率由 `culture` + `thinking` 属性决定
- 蒙题正确率由 `culture` + `luck` 属性决定
- 检查：答错 30% 概率翻正，答对 5% 概率改错
- 高考（第 36 月）：8 道题 + 文化课乘数（文化≥16 → ×1.2，<10 → ×0.6）
- 跨年时文化课效率根据文化属性重算（0.6x ~ 1.3x）

### 背景与特质系统（`talents.hpp`）

**7 种背景**（开局选择，不可更改）：

| 背景 | 核心效果 |
|------|---------|
| 家境优越 | 起始金钱×2 |
| 勤奋刻苦 | 文化课+3，每月心态+1 |
| 天赋型选手 | 思维+2、代码+1，心态上限 10 |
| 竞赛老手 | 经验+2 |
| 书香门第 | 文化+4、思维+1，起始金钱减半 |
| 草根逆袭 | 每月+3 AP，月收入+20% |
| 佛系心态 | 心态上限 14，焦虑概率减半，效率×0.9 |

**8 种可获取特质**（从模拟赛/刷题中有概率获得，最多 4 个）：

代码小能手、算法达人、心态稳定、快速学习、考场杀手、幸运星、钢铁意志、深度思考

### 焦虑系统

- 心态连续低于 4 达 2 月 → 概率触发焦虑
- 焦虑状态：学习效率×0.7
- 心态恢复后自动解除

### 遗忘系统

- 连续 2 月未学习的知识维度自动 -1
- 文化课同样受遗忘影响

## 商店系统重做

- 货币从"决心"改为"金钱"
- 商店不消耗 AP，从月活动页面直接打开弹窗
- 购买后价格递增（按难度不同增幅）
- 商品：思维/代码/细心/随机/心态/全面提升 + 速度/心理素质/经验/运气提升

## 月历引擎（`story.hpp`）

```
月份  日历月  事件
1-2   7-8月   暑假（集训可用）
3     9月     
4     10月    CSP-S
5     11月    NOIP + 期中考试
6     12月    
7     1月     WC + 期末考试
8     2月     
9     3月     省选
10    4月     期中考试
11    5月     APIO
12    6月     期末考试
13-24 高二（同上循环）
25-36 高三（6月=高考）
```

比赛资格按成绩自动判断（高一也能打省选）。

## 结算系统

月末结算按顺序执行：
1. 未用 AP → 睡觉（+健康 +心态）
2. 健康自然恢复 +2
3. 心态变化（文化、OI 均衡、比赛压力）
4. 遗忘检查
5. 金钱收入（基础 + 文化加成 + OI 成绩加成）
6. 焦虑检查
