# OI 重开模拟器 v0.3.0 更新说明

> 从 v0.2.0 月回合养成版 → v0.3.0 存档与目标感版本

## 一句话概括

补上存档这块最大短板，给三年生涯装上「中期目标（专题）— 生活管理（锻炼/熬夜）— 终局仪式感（结局矩阵）」三块拼图。

## 新增系统

### 存档系统（`save_system.hpp`）

- 每月进入行动阶段时自动写入 `savegame.txt`（exe 同目录）
- 主菜单「继续游戏」一键读档，从当前月的行动阶段继续
- 手写 key-value 序列化器，带魔数 `OISAVE <ver>` 与向前兼容；比赛临场状态不入档（下次开赛自然重建）
- 游戏日志只保留最近 200 条，防止存档膨胀

### 专题任务（`topics.hpp`）

- 11 个专题：9 个知识维度各一个 + 「手速特训」（迅捷）+「细心打磨」（细心）
- 同时最多进行 1 个；接受后 **3 个月内完成 4 次**匹配行动
  - 知识专题：学习该维度 / 打含该维度的比赛（主维度匹配题数 ≥2）
  - 手速特训：完成 4 场活动比赛；细心打磨：累计 6 次成功对拍/提交
- **精通奖励**（永久）：知识专题 → 该维度子问题思考时间 −1（下限 1）；手速 → 写码有效迅捷 +1；细心 → 错误率 ×0.9
- **逾期**：心态 −2，专题自动关闭；细心专题可凭历史对拍直接完成

### 生活节奏（E）

- **体育锻炼**（1 AP）：健康 +2，全游戏唯一 1AP 行动；本月 ≥2 次 → 病倒概率减半
- **熬夜**（月度开关，与停课互斥）：当月 +2 AP；结算健康 −3、焦虑概率 ×1.3
- **病倒**：结算时健康 ≤4 有概率发生（25% − 运气×1%，锻炼减半）；下月行动力 −2、心态 −1，惩罚必须吃满

### 保送与结局矩阵（`ending.hpp`）

- 入选国家集训队 → **保送锁定**：文化课心态惩罚与遗忘免除，高三 6 月高考替换为「庆功月」
- 结局矩阵：OI 高度（传奇 / 国家队 / 集训队 / 省队 / 无省队）× 高考档位（≥90% / ≥70% / <70%）→ 8 个结局称号，各配专属结语
- 结局称号：世界之巅 / 国旗之下 / 保送上岸 / 强基无忧 / 硝烟散尽 / 得失难言 / 文化课之神 / 泯然众人 / 复读的十字路口；健康归零另有「积劳成疾」
- 结局页新增**三年大事记**时间轴（自动从日志抽取获奖/晋级节点）

## 其他改动

- 奖金字段由 determinationReward 更名 prizeMoney；「考场杀手」「钢铁意志」特质真正生效
- 属性变更统一走 applyStatDelta，心态上限唯一真相为 moodCap（修复佛系背景下战斗内上限错误钳制为 12 的 bug）
- 考试月不再双重结算（原实现收入/遗忘/焦虑判定翻倍的 bug）
- 自定义模拟赛统一经 Contest::start(config) 进入，行为与正式赛一致（含入场心态-drop）
- 版本号升至 v0.3.0
